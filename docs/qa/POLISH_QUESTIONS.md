## Navigation grouping and badges

Keep Inbox, Clients, Library and Money as the four primary coach destinations. Retain the current secondary destinations and command access. Group review work under Inbox and communication under Messages in the existing secondary navigation if a grouping change is approved.

May the shell omit badges wherever an authorized total is unavailable? The client module provider retains visibility and numeral preferences. It carries no unread total. The coach message list has per-conversation unread counts and a pagination cursor. Summing the visible page could undercount. The coach shell navigation accepts no review total. A total available inside a restricted page does not establish access from every shell route.

## Batch 3 roster data

May the roster omit seven-day adherence and retain its existing order until it receives an authorized adherence value and cross-page attention rank? The mounted ClientList row schema includes status, active package and days left. Adherence and reason for attention are absent, and a page-local sort would misrepresent the full roster.
