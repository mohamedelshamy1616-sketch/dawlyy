# تجرّب DAWLYY على جهازك إزاي؟

دي معاينة محلية لمرحلة P2.5. Node وpnpm وPostgres موجودين على الكمبيوتر بالفعل؛ مش محتاج تثبّت حاجة ولا تعمل حساب Supabase. إعداد قاعدة البيانات في `packages/db/.env` بيجهّزه كلود مرة واحدة.

1. افتح PowerShell من فولدر المشروع `C:\Users\compuline\Desktop\dawlyy`.
2. انسخ الأمر ده وشغّله:

   ```powershell
   powershell -NoProfile -File tools\start_preview.ps1
   ```

3. استنى لحد ما يظهر إن السيرفر جاهز، وافتح [صفحة الدخول](http://localhost:3200/ar/login). سيب شباك PowerShell مفتوح.
4. في جزء **دخول للتطوير** اضغط على اسم الحساب اللي عايز تجرّبه. مش محتاج إيميل ولا باسورد، ومش محتاج تستخدم فورم الدخول العادي.

| الحساب | الاسم اللي هتختاره |
| --- | --- |
| مالك النشاط | كابتن محمد |
| عضو الفريق — كوتش | كابتن منى |
| عميل | أحمد حسن |
| عميل | سارة علي |
| عميل | محمود عادل |

كلهم تابعين لـ **Demo Coaching**. لو عايز تبدّل الحساب، اعمل تسجيل خروج من الشريط اللي فوق، وارجع لصفحة الدخول واختار اسم تاني. تقدر تشغّل نفس الأمر تاني؛ بيانات الديمو الموجودة مش بتتمسح ولا بتتكتب فوقها.

اللي تقدر تجرّبه دلوقتي: الدخول بحسابات التجربة، واجهة الكوتش وواجهة العميل، زر تبديل العربي والإنجليزي، وشكل التحميل والشاشات الفاضية بهوية DAWLYY. صفحة `/ar/login` اتظبط اتجاهها العربي علشان الكارت مايتقصّش على الموبايل؛ جرّبها وإنت مصغّر عرض الشباك. الروابط اللي لسه مش جاهزة بتفتح رسالة واضحة جوّه الواجهة.

الشاشات دلوقتي أغلبها هياكل فاضية، والأرقام لسه صفر. شغل Task 2 وما بعده لسه مش متاح للتجربة: التسجيل الحقيقي وإنشاء نشاط ودعوات الفريق، إدارة العملاء والباقات والاشتراكات، بناء ونشر البرامج، الأكل والمتابعات والقياسات، الدفع والرسايل وباقي إدارة النشاط. وجود حسابات وباقة وقالب برنامج في قاعدة البيانات مش معناه إن الشاشات دي اتبنت. مفيش برنامج منشور أو تمرين متعيّن لعميل دلوقتي.

علشان توقف التطبيق اضغط **Ctrl+C** في شباك PowerShell. قاعدة البيانات المحلية بتفضل شغّالة علشان المرة الجاية.

صور الشاشات وفهرسها في [docs/qa/screens/index.md](screens/index.md). كلود بيولّدها باختبار Playwright بالعربي والإنجليزي، بعرض موبايل 390 وكمبيوتر 1366 بكسل. لو الفهرس لسه بيقول إن مفيش صور، يبقى الاختبار لسه ماتشغّلش. الصور مش بتتجدّد تلقائيًا بمجرد فتح التطبيق.

لو التشغيل وقف، هتظهر رسالة بالعربي باسم الخطوة اللي وقفت. ابعت الاسم ده لكلود؛ مش محتاج تبعت ملف الإعدادات أو أي بيانات دخول.
