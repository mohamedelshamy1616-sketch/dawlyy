## Residual risks, accepted

- **Client-assignment removal is not in the replay fingerprint.** A staff member removed from a client can replay a cached response for that client within 24 hours with the same key and the same body. The assignment lives outside `AuthContext`; the cached body is one the staff member already received. Accepted for the beta.
- **In-memory rate limiter per instance.** The invitation preview throttle counts per server instance and trusts the first `x-forwarded-for` value. On Vercel the platform sets that header; verify on the deployed host (LAUNCH_RUNBOOK step 10 checks). The map grows with distinct keys for at most one minute.
- **Duplicate after a committed mutation if the receipt save fails, or a handler runs over 120 s.** The key is then released and a retry runs again. Rare; accepted.
- **Body ceilings apply before authentication, and two are large.** `idempotencyMiddleware` runs on every `/api/v1` mutation before router auth, so an anonymous caller can make the server buffer up to the route ceiling: about 37.6 MB for `POST /workout-sessions/sync` and about 6 MB for the CSV import routes (1 MiB elsewhere, 8 MiB for local media upload). The hosting platform's own request-body cap (Vercel functions: 4.5 MB; check on the deployed host) is the control in production; the real outbox never sends more than 1 MiB. Accepted for the beta; a later change can read the ceiling only after auth.
- **D2 window.** A session created while the client had access can keep receiving its own sets after expiry, and `PATCH /workout-sessions/{id}` and `/finish` are not gated. This is the client's own training record, not coach content. Accepted under decision 19.
- **Same-tenant push handover.** Within one tenant, a member who knows another member's push endpoint can take it over (decision 18). The endpoint is an unguessable capability; accepted.
- **Hosted checks owed.** Hosted auth throttling, Storage bucket limits (S2) and the deployed ingress body limit need deployed evidence (LAUNCH_RUNBOOK open notes).
